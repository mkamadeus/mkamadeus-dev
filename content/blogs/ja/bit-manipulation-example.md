## 背景

プログラミングロジックとスキルを向上させるために、CodeforcesやKattisなどのサイトを（不）定期的にチェックしています。ある日、私にとって興味深い問題に出会いました。最初、この問題はかなり挑戦的に見えたので、解こうとしました（問題は後のセクションで説明されます）。最初は解けませんでした — 問題に関連するパターンを見つけることができませんでした。急いでいなかったので、すでに真夜中だったため問題を放置しました。

ショッピングモールで何もしていないとき、問題を振り返って見てみると、どうやって解くかのアイデアが浮かびました — それは_ビット操作_を使用することでした！

## ビットマスクとは何ですか？

ビット操作を理解するために、まずビットマスクを理解する必要があります。これはビット操作演算で使用されるためです。
ビットは_「バイナリ桁」_の略で、ゼロと1を含む桁です。
整数変数は通常32ビットの制限があり、これは$2^{32}$の範囲を持つ32ビットで構成されることを意味します（2はビットの状態から派生 — 0または1で2つの可能性があります）。

一方、ビットマスクは、単純にブール値のセットとして使用される整数です。
ブール値は`False`または`True`の状態のみを持つため、$0$と$1$でも表現でき、そのためビットマスクと呼ばれます！
まとめると：

> ビットマスクは、整数がバイナリ形式でどのように表現されるかを利用し、コンパクトなブール値のセットとして使用できることを意味します。

## ビット演算子

ビット操作は、整数を表すビットを操作するために使用される技術です。
C++でよく使用されるビット演算子をいくつか紹介します。
これはビット演算子とその動作のみを示しています；使用法は例で示されます。
例のように純粋に使用することは珍しいです（低レベルプログラミングで作業する場合を除いて）。

## 左シフトと右シフト（`<<`と`>>`）

この演算は、整数のバイナリ形式を指定された値だけ左/右にシフトします。

左シフトは2による乗算と等価であり、右シフトは2による除算と丸めと等価であることに注意してください。コンパイラがすでにシフト演算を使用するようにコンパイルしている可能性がありますが、通常の除算演算よりも一般的に高速です。

```cpp
int x=5; // 101 in binary

x=5;
x=x<<1; //10 = 2 in decimal

x=5;
x=x<<3; //0 = 0 (can be seen as 0101)

x=5;
x=x>>1; //1010 = 10 in decimal

x=5;
x=x>>2; //10100 = 20 in decimal
```

### ビットOR（`|`）

2つの整数のバイナリ形式でビットごとにOR演算を行います。

```cpp
int x=5; // 101 in binary
int y=9; // 1001 in binary
int z=x|y;

/*
x = 0101
y = 1001
--------- OR
z = 1101 = 13 in decimal
*/
```

### ビットAND（`&`）

2つの整数のバイナリ形式でビットごとにAND演算を行います。

```cpp
int x=5; // 101 in binary
int y=9; // 1001 in binary
int z=x&y;

/*
x = 0101
y = 1001
--------- AND
z = 0001 = 1 in decimal
*/
```

### ビットNOT（`~`）

この演算子は整数のバイナリ形式のビットを反転します。
この演算は通常、他の演算子と組み合わせて使用されます；例えば、NANDやNOR演算を作成するためです。

> データ型に依存するため、ここでは例を提供しません。

### ビットXOR（`^`）

2つの整数のバイナリ形式でビットごとにXOR演算を適用します。
ビットを切り替えるのに便利です；以下の例を参照してください。

```cpp
int x=5; // 101 in binary
int y=9; // 1001 in binary
int z=x^y;

/*
x = 0101
y = 1001
--------- XOR
z = 1100 = 12 in decimal
*/
```

XORを使用して2つの整数を交換する巧妙なトリックを見たことがあるかもしれません。
これを達成するためにXORの性質を使用します。

```cpp
int a=3;
int b=5;

a=a^b; // a=6, b=5
b=a^b; // a=6, b=3
a=a^b; // a=5, b=3
```

## サンプル問題

> この[Kattis問題](https://open.kattis.com/problems/rationalsequence2)を参照してください。

### 問題文

**要約された問題文**: 無限の二分木が与えられます；各ノードは分子$p$と分母$q$を持つ分数で構成されます。左の子ノードは$\frac{p}{p+q}$に等しく、右の子ノードは$\frac{p+q}{q}$に等しいです。関数$F(n)$は、対応するノードから分数を返すように定義されています。ノードは以下の問題から取られた図に示されているように番号が付けられています：

上の図では、ルートノードは$p=1$と$q=1$の値から始まります。これは$F(1)=\frac{1}{1}$、$F(2)=\frac{1}{2}$、$F(3)=\frac{2}{1}$などを意味します。$p$と$q$が与えられたとき、$F(n)$が$\frac{p}{q}$に対応する$N$の値を返すことが求められます。

一見すると、この問題はビット操作に関連するものを表していないかもしれません。よく見ると、実際には2つの状態があります — 左または右のノードに行くこと（二分木のため）！この問題に対する私の視点を提供する前に、自分で解いてみることをお勧めします😀

### 洞察

問題は、キューを使用して幅優先探索（BFS）メソッドを使用することを示唆するかもしれません。
小さなNにある分数の場合、これは実行可能でしょう。
しかし、これは無限の二分木であるため、入力された分数がどこにあるかわかりません。

では、どのように問題を解決できるでしょうか？これが私の思考プロセスです：

- 剪定と比較して各テストケースから直接見つける方が（どういうわけか）良いです。時間とメモリがかかりすぎるためです。
- 各ノードをそのバイナリ形式で表現できます。
- 左ノードでは$p < q$、右ノードでは$p > q$です。

> **Q**: バイナリ形式を使用するとはどういう意味ですか？

まあ、最初、2番目、3番目のノードをバイナリ形式（`1`、`10`、`11`）で取ってみましょう。パターンを分析すると、左ノードでは最初のノードから`0`を追加し、右ノードでは最初のノードから`1`を追加すると最初に仮定できます。

> **Q**: なぜ機能するのですか？

*シンプル* — これは**二分木**です！もちろん、Nはバイナリ桁のパターンに従います！

トップダウンで問題を解決しているため、前から桁を追加する必要があります（左の場合は`0`、右の場合は`1`）。そのような結果をどのように達成しますか？指定された場所でビットをオンにするために、左シフト演算子とOR演算子を使用します。

```cpp
int result=0; // 000
int pos=2;
result|=(1<<pos); //turning on the 2nd bit from the right (0-based)

/*
(1<<pos) = 1 << 2 = 100 (in binary)
result = 000

000
100
---- OR
100
*/
```

これはC++で書かれた私の解決策です：

```cpp
#include<bits/stdc++.h>

using namespace std;

int main() {

  int t;
  scanf("%d", &t);

  while (t--) {
    int k;
    int p, q;
    scanf("%d %d/%d", &k, &p, &q);

    int res = 0, cnt = 0;
    while (!(p == 1 && q == 1)) {
      int tp, tq;
      if (p > q) //right
      {
        tp = p - q;
        tq = q;
        res |= (1 << cnt);
      } else //left
      {
        tp = p;
        tq = q - p;
      }
      cnt++;
      p = tp;
      q = tq;
    }

    res |= (1 << cnt);
    printf("%d %d\n", k, res);
  }
}
```

インデックス1から始めるため、初期ノードに到達した後に別の1を追加することに注意してください。

この解決策は、二分木を上に向かって移動するため、プログラムの時間複雑度を$O(\log{n})$にします。

## 結論

この問題サンプルは、ビット操作の使用法の1つに過ぎません。
プログラミングでの他の興味深いアプリケーションには以下が含まれます：
- `bitset`でのブール値の保存
- ビットマスクを使用したリバースバックトラッキング
- ビットマスクを使用した動的プログラミング
- など
